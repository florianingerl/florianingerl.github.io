**Known limitation, per your choice:** the session-cookie field is collected, but a browser drops a `Cookie` header set from JS and the `*facile.com` cookies are `SameSite=Lax`, so the POST only carries cookies if you're logged in to that site in the same browser. The component detects the returned login page and tells you to log in. If that turns out to be a problem, a proxy on the API server is the fix.
