When the button "Export to francaisfacile" is clicked.

Depending on the quizName, the topic should be exported either to
francaisfacile.com , anglaisfacile.com, italienfacile.com, espagnolfacile.com or
allemandfacile.com
In types.ts, the QuizNames are on the very top.

When the button is clicked, a modal dialog should appear where the user has to select:
1) The type of exercise. There is 1.1) Test à trous 1.2) Test avec des options et differents options pour
chaque question 1.3) Test avec des options et les mêmes options pour chaque trou

In the modal dialog, I want a group of radio buttons for these options, where you have to select exactly
one radio button.

When for example 1.1) Test à trous is selected, all the exercises from the database
for that topic and of type gapText , where there is only one gap with no options given, are fetched.
If 1.2) "Test avec des options differents" is selected, every exercise for the topic with type multiple
choice and every exercise of type gapText with exactly one gap and options given in the solution should be selected
If 1.3) "Test avec les mêmes options pour chaque exercice" is selected, then all the exercises from the database
of type gapText and of type multiple choice should be fetched. 

The chosen exercises should be displayed in a list in the modal dialog. Next to each exercise, there should be
a checkbox, so the exercise can be included in the export or not. At the top of the list,
there should be a Select All-Checkbox. 
Then all the selected exercises should be posted to the respective website (depending on the quizName). I think you need at least
10 questions or exercises. If the user has selected less than 10, then the missing ones should be a copy
of the last one.

All the exercises for the topic should be fetched from the database
using the function getAllExercises and then filter these exercises for the topic.


The gap in my app is in curly braces, but when the exercise is submitted to francaisfacile, then
the gap must become a star and the response (which is inside my curly braces), must become the
response on francaisfacile.

Example:
My app: 
A week has {seven} days.

When posted to francaisfacile:
q = A week has * days
r = seven
    
where q is question and r = response
